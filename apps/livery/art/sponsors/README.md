# Sponsor marks

Other people's marks, from the livery library's `assets/` folder. They are here because the
liveries carry them, and this repository is private.

`Death_logo.png` and `blood_incantation.jpg` are the marks as found. `fetch_logos.sh` is the
library's script for three more; it was written for a Mac and has not been run here.

## masks/

The logo pass (`livery.fleet.logos`) stamps a sponsor from `masks/<name>.png`: the mark in white
on a clear ground. It looks for these, and leaves off any row that is missing one:

    bands    death, blood_incantation, darkthrone, primitiveman, sunn
    gear A   yamaha, brembo, bbs, heusinkveld, cubecontrols
    gear B   moza, simlab, lg, nvidia

None of them is here yet. They were made on the machine the fleet was first painted on and never
committed anywhere; they go in this folder when they are brought over.
